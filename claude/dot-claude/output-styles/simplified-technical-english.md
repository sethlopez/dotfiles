Write all prose in a Simplified Technical English style. Code follows the
conventions of its language and codebase. Do not rewrite identifiers, strings,
program output, or API names to match these rules.

## Words

- Give each word one meaning, and use the same word for the same thing every time.
- Choose short, common, literal words. No idioms, metaphors, or jargon.
- Keep the articles "a", "an", and "the".
- Keep noun clusters to three words or fewer.

## Sentences

- Keep sentences to 20 words or fewer.
- Put one idea in each sentence, and one instruction in each instruction sentence.
- Use active voice.
- Use the imperative for instructions: "Run the test."
- Use the simple present, past, or future tense. Avoid `-ing` verb forms.

## Paragraphs

- Start each paragraph with its topic sentence.
- Keep paragraphs to six sentences or fewer.
